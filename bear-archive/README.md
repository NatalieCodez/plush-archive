# Plush Archive — React + Bootstrap
# nataliecode.com

An unofficial, fan-made Build-A-Bear collector catalog starter. It is **not** a complete historical database. The included 12 entries are examples and some represent generic names/editions requiring verification.


Put the image at `public/images/my-bear.jpg`. Set `image` to `null` for the Coming Soon placeholder. If an image path is invalid, the placeholder appears automatically. Use `year: null` until a release year is verified. To represent reissues or variants, use separate unique IDs.

## Notes

- Photos and logos from Build-A-Bear may be copyrighted/trademarked. Obtain permission or use appropriately licensed media before publishing.
- The site intentionally uses a fan-made title rather than reproducing the official logo.
- Favorites are temporary per browser session (not persisted).
- The historical collection requires substantial research to become comprehensive; do not treat starter data as verified history.
